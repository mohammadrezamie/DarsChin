# اصلاح UX صف ثبت و جلوگیری از انتخاب اشتباه درس‌های قدیمی

**مالک: ۲ نوامبر ۲۰۲۶ — وضعیت: تغییر در PR، بدون انتشار خودکار**

## مسئله و رفتار

۱. «درس انتخاب‌شده» یعنی حضور در فهرست فعلی انتخاب درس‌ها. اگر دانشجو بعداً آن را از فهرست برداشت اما گروهی از برنامه قبلی باقی ماند، آن گروه بدون حذف از سابقهٔ ذخیره‌شده، از صف **فعال ثبت و کپی سریع** کنار گذاشته می‌شود. هشدار موجود دربارهٔ انتخاب‌های قدیمی پابرجاست.

۲. وقتی درس هست ولی استاد اول هنوز تعیین نشده، صف باید بگوید «برای ساختن صف، استاد اول را انتخاب کن»، نه «هیچ درسی انتخاب نکرده‌ای».

۳. استادهای جایگزینِ هر درس داخل **همان ردیف صف** در یک بخش بازشونده نمایش داده می‌شوند. تبدیل جایگزین مجاز به استاد اول از همین بخش انجام می‌شود. گروه‌های غیرفعال، نامجاز یا نیازمند بررسی فقط با دلیل نمایش داده می‌شوند؛ دکمهٔ ارتقا برایشان غیرفعال است. **تصمیم نهایی همیشه در سرور و بر اساس چارت/شرایط همان دانشجو معتبر می‌شود.**

۴. رشته‌های فنی انگلیسی `HIGH/MEDIUM/LOW` در پیشنهادها معادل فارسی دارند. معیار موتور و نمره‌دهی تغییر نکرده است.

## پذیرش و بازگشت

- ورودی دارای دو درس و یک گروه انتخاب‌شده: صف فقط همان یک گروه و یک پیام راهنما برای درسِ بدون استاد دارد.
- حذف درس از سبد بدون پاک‌کردن گروه قبلی: گروه قدیمی از صف کپی غایب و هشدار موجود است.
- جایگزین مجاز: ارتقا به استاد اول با API برنامه؛ درحال‌ذخیره غیرفعال.
- جایگزین غیرمجاز: دکمه غیرفعال و علت قابل مشاهده.
- آزمون TypeScript، Vitest و Build روی SHA دقیق، سپس بازبینی صفحه موبایل/دسکتاپ. **تست کد معادل تأیید ظاهر در مرورگر نیست.**
- بازگشت با Revert PR؛ بدون تغییر DB، نقش، قوانین آموزشی، سرور مشترک یا نشر خودکار. دمو فعلاً موقتی و فعال باقی می‌ماند.
