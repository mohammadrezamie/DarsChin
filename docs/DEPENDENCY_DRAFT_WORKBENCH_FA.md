# گام اول ویرایشگر گرافی چارت — اتصال پیش‌نویس بدون انتشار

**تاریخ اجرا:** ۲۰۲۶/۱۰/۲۹  
**محدوده:** فقط مخزن درس‌چین. هیچ دیتابیس واقعی، سرویس تولیدی، سرور اصلی یا مخزن دیگری تغییر نکرده است.

## تجربهٔ قابل لمس در پنل خصوصی مدیریت

- مدیر در «قوانین آکادمیک ← نقشهٔ وابستگی» ابتدا چارت را **با نام** انتخاب می‌کند؛ فقط دروس آن چارت از API دریافت و بررسی می‌شوند.
- «کارگاه اتصال درس‌ها» یک حالت *پیش‌نویس* است: روی درس مبدأ و سپس درس مقصد در نقشه SVG بزن، یا هر دو را با select فارسی انتخاب کن. نوع اتصال از فهرست «پیش‌نیاز ←» / «هم‌نیاز ┄» انتخاب می‌شود.
- انتخاب از SVG با Enter/Space، فوکوس کیبورد و جایگزین select قابل‌دسترس است. در موبایل به‌جای تحمیل ژست drag دشوار، select و اقدام بزرگ لمسی در اولویت‌اند.
- گراف پیش‌نیازهای منتشرشده با فلش و هم‌نیاز با خط‌چین نمایش داده می‌شوند؛ اتصال پیشنهادی در رنگ سبز (و برای هم‌نیاز خط‌چین) ظاهر می‌شود.
- تمام نتایج در **همان مرورگر، حافظهٔ کامپوننت و همان بارگذاری چارت** هستند. دکمهٔ Undo آخرین اتصال و «پاک‌کردن پیش‌نویس» اضافه شده است. با عوض‌کردن چارت یا خروج از صفحه هیچ داده‌ای به سرور ارسال نمی‌شود.
- موتور پیشنهادی اولویت به‌صورت هم‌زمان روی **تمام زنجیرهٔ جدید** حساب می‌کند، ولی این عدد قانون رسمی آموزشی یا مجوز گرفتن درس نیست.

## قفل‌های ایمنی قبل از اتصال

`validateDraftLink` در `src/domain/dependency-draft.ts` جلوی این موارد را می‌گیرد: دسترسی بدون دریافت موفق دروس همان چارت، شناسهٔ درس خارج از همان چارت، اتصال درس به خودش، تکرار رابطهٔ قبلی یا پیش‌نویس، نوع اتصال نامعتبر، گراف موجودِ خراب و **چرخهٔ پیش‌نیازی در هر عمق زنجیره**. هم‌نیازهای دوطرفه به‌شکل مستقل پذیرفته می‌شوند و وارد رتبه‌بندی پیش‌نیاز نمی‌شوند. شاخه‌های OR با حفظ معنای اختیاری از تحلیل موجود عبور می‌کنند.

## آنچه هنوز انجام نشده — صریح و مهم

1. **ذخیره، حذف یا انتشار به دیتابیس نداریم.** قبل از فعال‌شدن دکمهٔ Publish، باید API نسخه‌دار، etag/قفل هم‌زمانی، مجوز `academic-policy.manage` یا `curriculum.manage` متناسب با scope، audit، تست درخواست هم‌زمان، و امکان بازگشت نسخه طراحی و اجرا شود. در غیر این صورت تغییرات واقعی دانشجو ناامن می‌شود.
2. **Drag-and-drop دقیق با handle و اتصال گرافی سه‌بعدی هنوز فعال نیست.** این نسخه click-to-connect با پیش‌نمایش است، نه ادعای تکمیل XMind/React Flow. افزودن `@xyflow/react` و احتمالاً `elkjs` بعد از نمونه‌سازی و تست کارایی/دسترس‌پذیری ارزیابی می‌شود.
3. گراف موجود فعلاً برای کارایی نمایش حداکثر ۳۶ گره دارد؛ جست‌وجو/انتخاب از select باید تمام دروس چارت را پوشش دهد. برای چارت‌های بزرگ، viewport مجازی/چیدمان خودکار لازم است.
4. قوانین رسمی دروس علوم و تحقیقات و چارت **معارف کارشناسی پیوستهٔ غیرپزشکی** تا دریافت اسناد از مالک نباید در موتور تحصیلی وارد یا عمومی شوند.

**مهم:** طراحی مدیر از صفر، صفحه‌بندی گسترده کاربران، ویرایش/ذخیرهٔ گراف سه‌بعدی و اتصال واقعی آموزشیار همچنان پروژه‌های آینده‌اند. این مرحله عمداً تنها «پیش‌نویس قابل‌بررسی» است.
