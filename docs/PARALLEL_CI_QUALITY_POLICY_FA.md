# سیاست دائمی گیت کیفیت موازی درس‌چین

**تصمیم مالک: ۶ آذر ۱۴۰۵ (۲۷ نوامبر ۲۰۲۶) — OWN-CI-PARALLEL-026.** وضعیت: طراحی و پیاده‌سازی اولیه در شاخهٔ آزمون؛ قبولی و ادغام منوط به شواهد Actions روی SHA دقیق است.

## اصل الزام‌آور
- با استفاده از Runnerهای استاندارد مخزن عمومی، پوشش آزمون را افزایش دهید و زمان سپری‌شده را با موازی‌سازی کم کنید، نه با حذف تست یا تضعیف assertion. محدودیت تعداد Jobهای هم‌زمان و صف GitHub همچنان برقرار است.
- تمام مجموعهٔ Vitest با تقسیم بومی `--shard=N/10` اجرا شود. ده بخش اولیه مستقل‌اند و `fail-fast: false` باعث می‌شود شکست یک بخش مانع جمع‌آوری نتیجهٔ بقیه نشود. فایل تازه بدون نگهداری فهرست دستی وارد تقسیم‌بندی می‌شود.
- سه کار مستقل دیگر شامل بررسی مستندات و ایمنی سورس، TypeScript و ساخت production همراه smoke واقعی API هستند. smoke باید پس از ساخت همان checkout اجرا شود.
- گیت تجمیعی با نام قبلی `Typecheck / Tests / Build` فقط با نتیجهٔ success همهٔ وابستگی‌ها عبور کند. شکست، لغو یا ردشدن مرحله پذیرفته نیست. فیلتر مسیر PR حذف می‌شود تا مستندات و فایل‌های پیکربندی نیز مشمول آزمون باشند. اجرای قدیمی همان ref هنگام ثبت کامیت جدید لغو می‌شود.
- `bun run qa:full` مسیر مستقل محلی و مرجع بازگشت است. هر Job از قفل Bun، کلید تصادفی مصنوعی و پوشهٔ دیتابیس موقت استفاده کند؛ هیچ Secret، سرویس واقعی SMS، VPS یا اطلاعات دانشجو وارد CI و گزارش عمومی نشود.
- نام گیت حفظ شده است، ولی تنظیم required check در Ruleset مالک باید جداگانه بررسی شود؛ هیچ تغییر Settings خودکار فرض نمی‌شود.

## پوشش لازم در مراحل توسعه
| حوزه | معیار افزایشی |
| --- | --- |
| موتور آموزشی | پیش‌نیاز، هم‌نیاز، انتخابی، تداخل، واحد کسری، ورودی و نسخهٔ چارت؛ تست مرزی و دادهٔ مصنوعی بدون اختراع مصوبه |
| احراز هویت و مجوز | CAPTCHA، انقضا، replay، OTP، نقش‌ها، مالکیت رکورد و دسترسی متقاطع؛ آزمون منفی |
| ذخیره و یکپارچگی | خطای دیسک، بازگشت اتمیک، restart، import/export، بازیابی و محرمانگی |
| نیازسنجی و برنامه‌ریز | قواعد شرطی، صف ثبت، چند ورودی، آمار و دسترسی مدیر |
| رابط کاربری | آزمون مرورگر واقعی در Chromium/Firefox/WebKit، موبایل، RTL، حالت روشن/تیره، دسترس‌پذیری و مسیر دانشجو/مدیر |
| زنجیرهٔ تأمین و انتشار | اسکن وابستگی و secret، ساخت افزونه و manifest، smoke API، نصب مستقل و rollback |

ردیف‌های مرورگر واقعی، پوشش خط/شاخه، آزمون بار، fuzzing و اسکن تکمیلی وابستگی نقشهٔ توسعه‌اند؛ این PR به‌تنهایی وجود یا اجرای آن‌ها را اثبات نمی‌کند. آزمون‌های پرهزینه را در گیت مناسب PR یا اجرای زمان‌بندی‌شدهٔ جداگانه اضافه کنید؛ تست محافظتی موجود از PR حذف نشود.

## معیار اندازه‌گیری و پذیرش
۱. در اجرای اول، تعداد فایل‌ها و تست‌های هر ده بخش، نتیجهٔ هر Job، SHA و مدت زمان واقعی ثبت شود. مجموع تست‌ها با اجرای کاملِ همان SHA مقایسه شود؛ هیچ بخش خالی، تکرار یا جاافتادگی قابل قبول نیست.
۲. حداقل چند اجرای قابل مقایسهٔ سرد و گرم را برای زمان صف، نصب، هر بخش و مسیر بحرانی اندازه‌گیری کنید. سپس تعداد بخش‌ها یا توزیع زمانی را تنظیم کنید؛ هدف سرعت، تضمین عددی قبل از اندازه‌گیری نیست.
۳. افزایش پوشش خط/شاخه با گزارش ابزار و آستانهٔ مبتنی بر خط پایه انجام شود؛ درصد پوشش کد با درصد آمادگی محصول یکی نیست.
۴. اجرای سبز CI جایگزین آزمون موبایل واقعی، سرویس بیرونی، استقرار یا تأیید رسمی مقررات نیست. هیچ مرج حساسی پیش از موفقیت گیت و بازبینی diff انجام نشود.
۵. در شکست یا لغو، فقط Jobهای لازم را دوباره اجرا کنید؛ شکست ناپایدار باید بررسی و مستند شود، نه اینکه با retry پنهان شود. در صورت مشکل ساختار جدید، Revert PR و اجرای کامل محلی راه بازگشت است.

## گیت مرورگر واقعی نسخهٔ یک — ۶ آذر ۱۴۰۵

پیگیری #156 و #151: سه Job مستقل Chromium، Firefox و WebKit با Playwright نسخهٔ ثابت 1.56.1 و چهار عرض ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰، روی پیش‌نمایش استاتیک ساختگی و loopback اجرا می‌شوند. ابزار مرورگر در مسیر موقت Runner نصب می‌شود و وابستگی محصول یا قفل Bun را تغییر نمی‌دهد. آزمون، RTL، overflow، تغییر/ماندگاری تم، منوی موبایل و بازگشت focus، ورود به دموی دانشجو و مدیر، لغو بازنشانی، صفحات ورود/ثبت‌نام/بازیابی، خطای اجرایی و منع درخواست خارجی را بررسی می‌کند. Screenshot و گزارش فقط دادهٔ ساختگی‌اند. گیت نهایی به موفقیت هر سه Job وابسته است. این آزمون جای دستگاه واقعی، مسیرهای احراز هویت زنده، دسترس‌پذیری کامل، پذیرش بصری مالک یا E2E پایدار را نمی‌گیرد. نتیجهٔ اجرای نخست باید ثبت شود؛ مرورگرها از شبکه عمومی Runner دریافت می‌شوند ولی درخواست‌های مرورگر فقط به loopback محدودند.

نخستین اجرای مرورگر [45960397543](https://github.com/mohammadrezamie/DarsChin/actions/runs/45960397543) در نصب هر سه موتور شکست خورد: `ubuntu-latest` به 26.04 منتقل شده و Playwright 1.56.1 از آن پشتیبانی نمی‌کند. هیچ آزمون رابط در آن سه Job اجرا نشد. Runner فقط برای Jobهای مرورگر روی Ubuntu 24.04 ثابت شد؛ هیچ موتور یا assertion حذف نشد. نتیجه اجرای تازه باید بررسی شود.
