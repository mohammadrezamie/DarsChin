# فوتر رسمی درس‌چین و قواعد چینش فارسی

**تصمیم قطعی مالک در ۲۰۲۶/۱۰/۲۶:** [OWN-031 و OWN-032](OWNER_DECISIONS_FA.md).

## مشخصات برند و حقوق
- محصول: **درس‌چین**، یکی از پروژه‌های **شرکت تکین نوآوران آینده**.
- آدرس سایت شرکت: **https://tnacompany.ir/**؛ لینک فوتر با نام واضح، دسترس‌پذیر و `https` و بازشدن در زبانهٔ جدید با `rel="noopener noreferrer"`.
- متن حقوق پیشنهادی و مصوب برای نمایش: **«کلیهٔ حقوق مادی و معنوی سامانهٔ درس‌چین متعلق به شرکت تکین نوآوران آینده است.»**
- درج نشانهٔ © و سال جاری، ترجیحاً سال فارسی متناسب با تاریخ مراجعه‌کننده. © به‌تنهایی به معنی ثبت رسمی علامت تجاری نیست و نباید چنین ادعایی اضافه شود.
- **هیچ تغییری در سایت یا مخزن شرکت تکین** تا درخواست جداگانهٔ مالک انجام نمی‌شود. معرفی رابطهٔ محصول صرفاً در درس‌چین منتشر می‌شود.
- بدون تأیید اسناد رسمی، شماره ثبت شرکت، نشانهٔ «®»، عبارت «ثبت‌شده»، «دارای مجوز رسمی دانشگاه» یا هر گونه وانمودسازی تأیید دانشگاه درج نشود.

## استفاده و نمایش
- یک کامپوننت `src/components/SiteFooter.tsx` روی تمام مسیرها: لندینگ، دمو، صفحهٔ دانشجو، پنل مدیریت، صفحات ورود و بازیابی و ... .
- از تکرار عنصر معنایی `footer` در هر صفحه جلوگیری شود؛ توضیحات فنی محلی دمو در قالب متن/aside جدا باقی می‌مانند.
- فوتر در موبایل **وسط‌چین** و خوانا و در نمایشگر عریض متوازن باشد. فارسی RTL می‌ماند؛ آدرس اینترنت و کد انگلیسی LTR فقط در متن مربوط.
- لینک باید بدون وابستگی به سرور تولیدی و در نسخهٔ دمو نیز کار کند.

## اصلاح باگ عمومی CSS
- قاعدهٔ `.darschin-page :where(h1, h2, h3, h4, p) { text-align: right; }` به دلیل تحمیل اجباری راست‌چینی به محتوای عمداً وسط‌چین، باید حذف شود. جهت کلی سند `rtl` و راست‌چین‌بودن **پیش‌فرض** باقی می‌ماند اما `text-center`/چینش موردی محترم شمرده می‌شود.
- استفاده از `dir=ltr` برای کد، شماره تلفن، نشانی وب و زمان به‌معنای چپ‌چین‌کردن متن فارسی نیست.

## معیار پذیرش
1. فوتر در تمامی مسیرها دقیقاً یک بار و با لینک درست `tnacompany.ir` دیده شود؛ اطلاعات ساختگی یا تکین نامرتبط درج نشود.
2. متن حقوق درست، سال به‌روز و سازگاری با دارک و لایت.
3. صفحه‌های نمایشی عمدیِ وسط‌چین (Hero، پیام حالت خالی، بخش CTA) دیگر از قاعدهٔ CSS مجبور به راست‌چین نشوند؛ متن‌های طولانی فارسی در فرم و جدول همچنان راست‌به‌چپ بمانند.
4. تست‌های SSR و بررسی CSS و QA موبایل ۳۲۰/۳۹۰/۴۳۰، قبل از ادغام روی همان SHA اجرا شوند؛ از وضعیت بررسی‌نشده ادعای تست پاس‌شده نشود.

**وضعیت اولیه:** تصمیم روی `main` ثبت شده؛ تغییر کد در شاخه و PR مستقل برای جلوگیری از تداخل با PRهای توسعهٔ نیازسنجی انجام می‌شود.

## اجرای نهایی طرح روی نسخهٔ جدید — ۲۰۲۶/۱۰/۲۸

- فوتر مشترک `SiteFooter` به پوستهٔ اصلی React منتقل شد؛ لندینگ، دموهای دانشجو/مدیریت، صفحهٔ راهنما، ورود/ثبت‌نام/بازیابی و میز کارهای واقعی دقیقاً یک فوتر حقوقی دارند. توضیح اختصاصی هر دمو در `aside role=note` باقی است.
- نمایش متن مالکیت مطابق مصوبهٔ اولیه، نام شرکت و پیوند HTTPS به `tnacompany.ir` با `noopener noreferrer` و © سال شمسی پویا اجرا شد. هیچ شماره‌ثبت/مجوزی جعل نشده است.
- فوتر در صفحات دارای داک پایین موبایل به‌اندازهٔ `pb-28` فاصلهٔ امن می‌گیرد و متن پشت داک پنهان نمی‌شود؛ در دسکتاپ همان فاصلهٔ معمول باقی است.
- قاعدهٔ CSS که تمام تیترها/پاراگراف‌ها را به‌زور راست‌چین می‌کرد برداشته شد، درحالی‌که پیش‌فرض راست‌به‌چپ سایت حفظ شد.
- **گیت اجراشده روی فایل‌های GitHub:** ۳۲۷ فایل غیرباینری دقیقاً با hash موردانتظار شاخهٔ `94466ca576d0feb858a4bc2cec7d31e81543e31e` تطبیق داشتند؛ ZIP افزونه تولیدی از hash audit مستثنا بود. `bun run qa:full` شامل نصب قفل‌شده، TypeScript، ۳۵۴ تست/۶۵ فایل، Vite+Express build و API smoke با `exit 0` پاس شد.
