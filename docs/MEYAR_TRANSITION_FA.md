## مرز امنیتی

درس‌چین سامانهٔ مستقل برنامه‌ریزی و نیازسنجی است. رمز، کد ملی، کوکی نشست یا توکن معیار را دریافت نمی‌کند. هیچ درخواست خودکار ورود، پرداخت شهریه یا انتخاب واحد رسمی به معیار ارسال نمی‌شود. دامنهٔ جدید فقط برای لینک عمومی استفاده می‌شود؛ manifest افزونهٔ قدیمی، داده‌های تاریخی، API و VPS در این مرحله تغییر نمی‌کنند. فایل استاندارد JSON/CSV/TSV باید فقط شامل دادهٔ مجاز دروس باشد و طبق صف موجود به تأیید مدیر برسد؛ فایل خروجی بومی معیار هنوز پشتیبانی تأییدشده ندارد.
