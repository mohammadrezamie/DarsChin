# طرح اجرایی UI-first درس‌چین برای جذب دانشجو — از ۲۰۲۶/۱۰/۲۶ تا هدف ۲۰۲۶/۱۱/۲۶

**مالک/تصمیم:** OWN-038 در `docs/OWNER_DECISIONS_FA.md` روی PR #42 ثبت می‌شود؛ تغییرات UI در [PR #34](https://github.com/mohammadrezamie/DarsChin/pull/34). **این تاریخ یک هدف کیفیت/تکمیل است، نه تعهد انتشار بدون تست.**

## ترتیب قطعی کار وقتی مالک می‌گوید «ادامه بده»

۱. ابتدا آخرین دستور مالک و مستندات مرتبط GitHub را بررسی کن؛ سپس **واقعاً رابط کاربری را توسعه بده یا دیباگ کن**. جمع‌کردن UI/UX حرفه‌ای، چشم‌نواز، قابل فهم، با هویت بصری یکپارچه و تجربهٔ سریع دانشجو اولویت این فاز است؛ بک‌اند را امن و کارا نگه‌دار و ایرادهای P0 عملکرد، امنیت و صحت داده را فوراً رفع کن. مستندات باید همراه کد باشند، نه جایگزین آن.

۲. مسیر کاربر: **لندینگ → دمو بدون حساب → پنل دانشجو → چارت/دروس ارائه‌شده → تداخل‌سنج و برنامهٔ هفتگی → صف سریع ثبت**؛ سپس پنل مدیریت و نیازسنجیِ اولویت‌دار، فرم‌ها، پیام‌های خطا و حالت‌های خالی. فوتر سازمانی از PR #38، و تغییرات آموزشی دقیق از PR #37 باید **بعد از رفع تعارض و تست** با UI همگرا شوند.

۳. **طراحی:** زبان فارسی روان و راست‌به‌چپ صحیح (راست‌چین اجباری برای همهٔ محتوا ممنوع)، Vazirmatn محلی، تعادل فضای خالی و تراکم اطلاعات، تیتر و رنگ و سایهٔ هماهنگ، حالت تیره/روشن خوانا، انیمیشن محدود و احترام به `prefers-reduced-motion`. کاربر باید در نخستین اسکرین دمو و مسیر بعدی را به‌روشنی بفهمد؛ کدهای دمو و اطلاعات آموزشی غیرمصوب نباید «قطعی» نشان داده شوند.

## اقدامات انجام‌شده روی شاخهٔ Draft PR #34 در ۲۰۲۶/۱۰/۲۶

- کنترل روز/شب موبایل از ۱۱۶ پیکسل به **۴۴ پیکسل با انتخابگر بومی قابل دسترس** تغییر کرد تا هدر در ۳۲۰ پیکسل جا شود.
- ورود از هدر لندینگ روی موبایل قابل دسترسی شد، لوگو/فاصله‌ها کاهش یافتند، CTA دمو/ثبت‌نام برجسته‌تر شدند و کارت‌های امتیاز پیش‌نمایش در عرض‌های باریک فشرده‌تر چیده شدند.
- مزیت‌های بالای صفحه به سه کارت خلاصهٔ کم‌ارتفاع موبایل تبدیل شدند؛ شرح کامل‌تر در ابعاد بزرگ نمایش داده می‌شود.
- بخش شروط آموزشی و پیشنهاد درس با چینش تازهٔ سازگار با تبلت، تیتر/کارت خواناتر و محدودکردن ادعاهای **غیرمستند** بازنویسی شد؛ انیمیشن‌های این دو بخش از ترجیح کاهش حرکت پیروی می‌کنند.
- اصلاحات قبلی این PR برای تداخل‌سنج و صف ثبت حفظ شدند.

**تست و تأیید:** این تغییرات در GitHub هستند ولی هنوز نه `bun run verify` روی آخرین SHA و نه بررسی واقعی مرورگر/آیفون در ابعاد جدول اجرا شده است. تا انجام آن‌ها، ادعای کیفیت «پرفکت» و آماده‌بودن نسخهٔ مشتری **مجاز نیست**.
