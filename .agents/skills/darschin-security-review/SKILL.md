# بازبینی امنیت
الهام از `tna-static-security-audit` و الگوهای `tna-safe-dependencies-update`؛ منشور دائمی امنیت درس‌چین و SECURITY.md الزام بالاتر دارند.
1. مدل تهدید و مسیر واقعی درخواست را تعیین کنید: احراز هویت، کنترل نقش و اسکوپ واحد/ورودی، مالکیت رکورد، validation، XSS، SSRF، CSRF، فایل و خروجی CSV.
2. تست انکار دسترسی و محدودیت حجم/تعداد را کنار تست موفقیت بسازید. مخفی‌کردن UI مجوز سمت سرور نیست.
3. خطای ذخیره و rollback، دادهٔ خصوصی در لاگ، فایل موقت و اسرار را بررسی کنید. فقط از fixture مصنوعی استفاده کنید؛ مقدار محرمانه در خروجی ننویسید.
4. اسکن سورس و lockfile در محیط ایزوله؛ `bun run repo:public-check` فقط HEAD را می‌سنجد و گواه پاکی تاریخچه نیست. اسکن زنده/تهاجمی و تغییر سرور مجاز نیست.
5. شدت، مسیر، دلیل، بازتولید امن، آزمون رگرسیون و SHA را ثبت کنید. حادثهٔ تاریخی را بدون مدرک نبندید.
