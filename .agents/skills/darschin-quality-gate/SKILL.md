# گیت کیفیت و وابستگی‌ها
الهام از `tna-free-local-ci` و `tna-safe-dependencies-update`.
1. Node 22+، Bun و bun.lock فعلی را بررسی کنید؛ بدون دلیل سازگار مدیر بسته یا چارچوب را عوض نکنید.
2. نصب قفل‌شده، آزمون متمرکز، سپس `bun run verify` و در صورت امکان `bun run qa:full` در پوشهٔ دیتابیس موقت و کلیدهای تازه. وضعیت هر مرحله ثبت شود.
3. ارتقای وابستگی با مستند رسمی نسخه، سازگاری، advisory، اثر قفل و rollback؛ major upgrade مستقل و بدون انتشار خودکار.
4. هیچ runner روی VPS مشترک راه‌اندازی نشود؛ ابزار بیرونی یا هزینهٔ جدید نیازمند مجوز مناسب است.
5. ادغام فقط با گیت واقعی روی HEAD دقیق، سپس بررسی مستقل main. صف، skip، build preview و موفقیت قدیمی شاهد عبور SHA جدید نیستند.
