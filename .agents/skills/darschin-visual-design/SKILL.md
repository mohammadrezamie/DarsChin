# طراحی بصری درس‌چین
الهام از مهارت‌های `frontend-design`، `tna-theme-day-night` و `tna-ux-journeys`؛ دستور فعلی مالک مقدم است.
1. قبل از تغییر، مسیرهای واقعی و هدف کاربر را بررسی کنید. طراحی از کار دانشجو شروع شود، نه تزئینات.
2. معیار جاری: سطوح سفید/خاکستری، آبی دانشگاهی محدود به اقدام اصلی، سرمه‌ای در تم شب؛ از گرادیان و رنگ انباشته و تزئین پرهیز کنید. سبز، زرد، قرمز برای معنای وضعیت باقی بمانند. پالت ردشده را بازنگردانید.
3. از توکن‌های موجود، React و Tailwind استفاده کنید؛ کنترلر تم دوم نسازید. حالت انتخاب، خطا، خالی، انتظار، موفقیت و غیرفعال را طراحی کنید.
4. طرح را در زمینهٔ واقعی RTL و موبایل/دسکتاپ بررسی کنید؛ حرکت فقط پاسخ به تعامل، با رعایت reduced motion.
5. پیش‌نمایش دقیق SHA و شواهد هر دو تم را ارائه کنید؛ تصویر شماتیک یا Build جای مشاهدهٔ مرورگر نیست. نظر مالک دربارهٔ ظاهر قبل از ادعای پذیرش لازم است.
